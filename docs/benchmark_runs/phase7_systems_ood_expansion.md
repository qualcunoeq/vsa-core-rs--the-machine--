# Phase 7 — Expanded independent systems evidence

The Phase 6B vertical was frozen before widening evaluation. This phase adds
an implementation-independent corpus generated by
`scripts/generate_system_ood_v2.py`; expected solutions use Python
`fractions.Fraction`, not the Rust executor.

## Corpus

`data/algebra_systems_ood_v2.json` contains 200 base cases and 200 semantic or
mutation variants:

- 120 unique 2x2 systems;
- 30 inconsistent systems;
- 20 dependent systems with infinitely many solutions;
- 20 nonlinear systems;
- 10 malformed or ambiguous systems;
- reordered equations, sign changes, prose forms, semicolons, and
  `together with` / ordered-pair rewrites.

## Initial mutation findings

The first run exposed three real boundary defects:

1. Degenerate systems were formally authorized before the executor rejected
   them (`100` classifier false accepts).
2. Conditional questions such as `Can x,y be determined ...?` were treated as
   solve requests (`10` false authorizations).
3. A leading negative coefficient in prose lost its sign during fragment
   scanning, producing incorrect positive results.

These were fixed in the typed authorization and equation-fragment paths. No
new solving capability was added.

Classification refusals were explicit:

```text

```

The frozen 48-case OOD corpus also remained clean: 0 false authorizations,
0 false denials, 24/24 stable rewrite decisions/results, and 100% replay.

## Ablations

Command:

```text
cargo run --release --bin system_ood_ablation -- data/algebra_systems_ood_v2.json
```

Results:

```text
classifier bypass false accepts: 100
valid replay accepts: 240/240
tampered receipts rejected by replay: 240/240
tampered receipts accepted by no-replay counterfactual: 240
```

The ablations demonstrate that both boundaries are active: ignoring
rank/uniqueness would accept 100 degenerate systems, and skipping replay would
accept every tampered unique-solution receipt.

## Governed regression

The 1,000-case governed benchmark retained zero false authorizations and zero
false denials across recurrence, algebra, propositions, method selection, and
adversarial tiers. Focused algebra, systems, OOD, and expanded-corpus tests
passed.

## Decision

The expanded corpus has no residual failure cluster in this vertical. No new
algebra capability is justified yet; the next vertical should be selected from
a genuinely independent benchmark rather than from infrastructure speculation.
