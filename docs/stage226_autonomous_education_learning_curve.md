# Stage 226 — autonomous education learning curve

This is the first program-level transfer gate after the multi-gap source
acquisition campaign. A permanently partitioned, independently generated
1,000-case curriculum is presented as raw technical text. The same corpus is
evaluated against the parent memory before acquisition and against a clone
after three source catalogs are selected, validated, and appended.

Results:

* corpus: 600 development, 200 validation, and 200 sealed cases;
* baseline v3 catalog availability: 0/3 and baseline authorization: 0;
* 180/180 source-memory gaps replayed across 3 exact clusters;
* 4/4 plans replayed, with 3 promotable plans and 1 broad distractor refused;
* 9/9 source mutations rejected;
* 3/3 acquired catalogs retrieved uniquely and replay-verified;
* post-acquisition: 600/600 supported cases authorized correctly;
* 200/200 ambiguous cases preserved and 200/200 unsupported cases refused;
* 1,000/1,000 terminal decisions exact, replayed, and tamper-rejected;
* zero false authorizations or denials;
* parent memory and curriculum manifest unchanged.

The sealed partition is not used to choose or modify a source module. This is
shadow curriculum transfer only; no HLE answers, live registry, or production
route are touched.
