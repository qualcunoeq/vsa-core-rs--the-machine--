# Contributing to The Machine

The Machine is released under [The Machine Research Source License 1.0](LICENSE). Contributions are welcome, but they are accepted only on the terms below, so that the project can continue to be licensed under the research license and under commercial licenses.

## Before you contribute

1. Read [CLA.md](CLA.md). By opening a pull request, or by otherwise submitting a contribution, you agree to it. If you do not agree, do not submit a contribution.
2. Keep the contribution your own work, or make sure you have the right to submit it.
3. Do not submit code copied from another project unless its license permits the contribution and you disclose the source and license.

## How to contribute

1. Open an issue for anything larger than a small fix, so the approach can be agreed first.
2. Fork the repository and create a branch.
3. Make the change. Keep it focused. Match the existing code and documentation style.
4. Add or update tests. The library suite is run with `cargo test --lib --locked -j 3`. See [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) for the full workflow.
5. Open a pull request. In the description, state the purpose of the change and any relevant context.

## What not to contribute

- Code that copies or incorporates third-party source without a compatible license and disclosure.
- Changes that re-license, remove notices, or add a different license.
- AI-generated code that you cannot license under the CLA, or that reproduces third-party code.

## Review and acceptance

The author reviews pull requests and may accept, request changes, or decline. Acceptance merges the contribution under the terms of [CLA.md](CLA.md). There is no obligation to accept any contribution, and no compensation is owed for a contribution.
