# Phase 8 — Independent Proposition Proof Vertical

This milestone freezes the validated linear-systems vertical and evaluates the
proposition proof kernel against a separate descriptor corpus. The corpus is
generated by `scripts/generate_proposition_ood.py`, whose Python-side oracle
labels proof families independently of the Rust `proposition_benchmark` case
factory.

## Corpus

- 500 descriptors across 16 proof families;
- positive rules: reflexivity, identities, commutativity, distributivity,
  symmetry, transitivity, nonnegative absolute value, and universal
  introduction;
- negative/adversarial rules: missing premises, unknown hypotheses, distractor
  hypotheses, wrong certificates, unknown theorems, converse confusion, and
  wrong conclusions;
- 242 semantic-preserving rewrite pairs with alternate values or bound-variable
  presentation;
- expected authorization is supplied by the independent Python descriptor
  oracle, not inferred from the Rust checker.

## Ablations

The assumption-matching counterfactual would accept all 92 negative cases
whose validity depends on a missing, mismatched, or omitted premise. The
production checker rejects them all.

Replay was independently rerun for all 288 accepted cases. Every tampered
expected target was rejected (`288/288`); a no-replay counterfactual would
accept all 288 forged receipts.

These controls demonstrate that local-assumption matching and proof replay are
security boundaries rather than diagnostic decoration.

## Scope and next step

This is a pilot-sized independent proposition corpus, not a universal theorem
correctness claim. The vertical is now ready for a larger externally authored
corpus containing implication/converse traps, distractor premises, quantifier
scope cases, and two-to-four-step derivations. No new proof capability or
automatic theorem acquisition is justified by this run; future expansion
should follow the first independent failure cluster.
