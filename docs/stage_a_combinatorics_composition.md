# Stage A: combinatorics composition campaign

The bounded counting substrate was composed through explicit, typed routes;
the benchmark does not authorize a downstream method merely because a scalar
count is available.

## Routes

* favorable/total counts to a finite exact probability distribution;
* complete-graph edge count to an adjacency matrix and linear-algebra artifact;
* an explicitly declared count coefficient to a modular inverse;
* an explicitly declared count as the initial state of a finite affine trace.

Each route preserves the source artifact, semantic declaration, and replay
receipts of every participating pack. Ambiguous counts stop before routing;
weighted graphs, invalid arithmetic domains, oversized counts, and dynamics
beyond the finite horizon are refused.

The independent corpus is recorded in
`docs/stage_a_combinatorics_composition.json` with SHA-256
`682c191f021ad60c2a6269dc10c1139e874fe797e47b4a049cb4b6bd8bedfbce`.
