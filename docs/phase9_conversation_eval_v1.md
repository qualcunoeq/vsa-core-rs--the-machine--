## Interpretation

* A wrong delivered answer and a system abstention are different outcomes: the first is an oracle error, the second is self-rejection. They are never summed.
* Coverage is how often the system answers at all; a high coverage with a high oracle-wrong rate is not success.
* The holdout set is reported but never gated: it exists to be untouched.
