GOVERNED CLAIMS:

1. A molecular formula uses element symbols and subscripts to represent the
   types and counts of atoms in a molecule.
2. A balanced chemical equation has equal atom counts for every element on
   both sides of the reaction arrow.
3. Integer coefficients in a balanced equation encode relative amounts and
   can be used as stoichiometric factors.

The implementation stores these claims as source metadata and validates only
the bounded transformations justified by them. It does not infer unlisted
chemical properties.
