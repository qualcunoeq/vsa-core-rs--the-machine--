# Goal 1/2 — independent external mathematics exam baseline

This is the first baseline against a public, naturally authored release rather
than a corpus generated by The Machine. The source is the MATH dataset
(Hendrycks et al., 2021), pinned to the recorded dataset revision and license
in `data/external_math_exam_v1/manifest.json`.

The local release contains 4,000 original prompts:

* 3,000 development cases;
* 1,000 sealed holdout cases;
* original wording preserved;
* no answers in `questions.jsonl`;
* only SHA-256 answer hashes in both oracle files;
* sealed plaintext answers are not available to the router or development
  code.

The baseline invokes the unchanged `QuestionRouter::orchestrate` path. It
does not modify the curriculum manifest, production registry, or authorization
policy. Every case receives exactly one terminal status:

* `correct_authorized`;
* `incorrect_authorized`;
* `false_abstention`.

Because every MATH case has an externally supplied supported answer, an
abstention is recorded as a benchmark false abstention. This is distinct from
an unsafe authorization error: `false_authorizations` counts only an incorrect
answer actually authorized by The Machine.

## Results

| Partition | Cases | Correct authorized | Incorrect authorized | False abstention | False authorization |
|---|---:|---:|---:|---:|---:|
| Development | 3,000 | 0 | 0 | 3,000 | 0 |
| Sealed | 1,000 | 0 | 0 | 1,000 | 0 |

First-failing-gate counts:

| Gate | Development | Sealed |
|---|---:|---:|
| Missing knowledge | 2,097 | 678 |
| Language normalization | 485 | 182 |
| Missing method | 372 | 132 |
| Missing prerequisite | 40 | 8 |
| Representation gap | 6 | 0 |

Governance and replay results:

* incorrect authorizations: **0**;
* registry/curriculum mutation: **false**;
* replay failures: **0**;
* replay not applicable: 3,000 development and 1,000 sealed, because no
  answer was authorized;
* all 4,000 cases were evaluated with the same producer commit and curriculum
  manifest hash.

The machine-readable reports are:

* [`goal1_external_math_exam_release_manifest.json`](goal1_external_math_exam_release_manifest.json)
* [`goal1_external_math_exam_baseline_development.json`](goal1_external_math_exam_baseline_development.json)
* [`goal1_external_math_exam_baseline_sealed.json`](goal1_external_math_exam_baseline_sealed.json)
* [`goal3_externality_audit_external_math.json`](goal3_externality_audit_external_math.json)

The separate externality audit found zero exact development/sealed prompt
duplicates and zero overlap with the inspected local artifacts. It did find 60
parameterized source-level template matches; these are retained as an explicit
review signal rather than silently counted as contamination. Their prompts and
source item identifiers are distinct, so the release is marked eligible with
the verdict `independent_external_release_template_overlap_reviewed`.

Reproduce with:

```text
EXTERNAL_MATH_EXAM_SPLIT=development \
  cargo run --quiet --bin external_math_exam_baseline

EXTERNAL_MATH_EXAM_SPLIT=sealed \
  cargo run --quiet --bin external_math_exam_baseline
```

The evaluator records first-gate traces and answer hashes. It does not expose
sealed plaintext answers to routing or acquisition code. This is a baseline,
not an improvement campaign; no repairs were made after observing these
results.

The release itself is reproducible with
`scripts/build_external_math_exam.py`; rebuilding from the pinned train/test
parquet inputs produced byte-identical question, oracle, and manifest hashes.
