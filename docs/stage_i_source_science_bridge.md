# Stage I: retrieved law to governed execution

This shadow integration allows a source-derived law claim to reach the exact
science interpreter only after retrieval returns one corroborated object with
complete provenance. Conflicting and missing claims never execute. The
consumer remains responsible for the typed law request; retrieval does not
mutate a registry or promote a claim into a fact.

The 240-case corpus contains 120 supported retrieval-and-execution routes, 40
conflicting claims, and 80 missing claims. The generated report is
`docs/stage_i_source_science_bridge.json`.
