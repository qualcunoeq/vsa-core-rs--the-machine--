# Phase 33 — Law-reference grounding and equation-shape audit

Phase 32 showed that the law lookup and equation-binding primitives were not
receiving the typed requests they require. Phase 33 adds a shadow-only
grounding layer and diagnoses the four non-bindable equation cases without
extending the AST or authorizing HLE answers.

## Grounding contract

`LawGroundingRequest` separates:

* explicit law aliases;
* a described phenomenon;
* domain constraints;
* expected variables and requested output;
* nearby equations and context.

`ground_law_reference` only accepts an alias or descriptive term that exactly
matches a catalog record (after punctuation normalization), then applies domain
and variable checks. A broad subject label or a substring such as `law` cannot
select a record. Overloaded aliases remain ambiguous, and absent references
remain missing.

The independent grounding corpus contains six cases:

| Expected | Result |
| --- | --- |
| Unique explicit alias | Unique |
| Unique descriptive relation | Unique |
| Overloaded energy alias | Ambiguous |
| Unknown law | Unsupported |
| Missing reference | Missing |
| Broad `law` label | Unsupported |

All six replay checks passed.

## HLE audit result

The eight Phase 32 named-law candidates produced:

* 0 unique groundings;
* 0 ambiguities;
* 8 unsupported or missing groundings;
* 0 HLE authorizations.

This is expected: the fixture registry intentionally contains no HLE-specific
law content. The audit demonstrates that the new layer refuses the broad or
domain-only cues generated by Phase 30 instead of inventing law identities.

## Equation-shape result

The four equation-binding candidates were classified without adding AST
extensions:

| Case shape | Count | Why it is not a binding artifact |
| --- | ---: | --- |
| Matrix property with random entries | 1 | event-defined random index and diagonalizability predicate |
| Model identifiability choice | 1 | learnability/model-class question |
| Program parameter selection | 1 | code hyperparameter comparison |
| Statistical sampling bound | 1 | concentration bound over stratified graph sampling |

All four received shape classifications, but none reached a typed equation or
solver route. This prevents a generic “special equation” escape hatch.
