## Key Findings

- Functional correctness was stable for all parsed rows: every JSONL result passed.
- The current benchmark set is not discriminating enough in ablation mode: most feature removals still report perfect accuracy, so harder adversarial cases are needed.
- Memory retrieval is the dominant bottleneck. Memory-pressure reached 100,000 facts and stayed correct, but average latency climbed into multi-second to tens-of-seconds territory.
- Deep chain QA is correct but slow at high depth. Depth 250 averaged roughly 17.5 seconds per query in this run.
- Medium adaptation completed reliably with zero regression in parsed outputs.
- Large/max adaptation did not emit JSONL in three runs, indicating an execution-time or scaling failure rather than a correctness failure.
