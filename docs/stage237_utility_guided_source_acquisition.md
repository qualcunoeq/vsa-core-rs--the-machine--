# Stage 237 — utility-guided source acquisition

This stage connects utility-ranked curriculum planning to a bounded shadow
acquisition run. Six provenance-derived source modules (21 records) produce
120 replayable knowledge gaps and seven replayable proposals. A budget of six
cost units selects the three highest-ranked authoritative modules; the
unselected modules remain unavailable and therefore fail closed.

Results:

* 6/6 modules discovered from the frozen source corpus;
* 21/21 source records represented;
* 120/120 gap observations replayed across 6 clusters;
* 7/7 proposals replayed;
* 3 modules selected at utility 180 and cost 6, exactly consuming the budget;
* 600/600 source cases classified exactly;
* 300/300 selected cases authorized and 300/300 unselected cases refused;
* 1,800/1,800 frontend replays and tamper rejections;
* 300/300 downstream replays;
* 3/3 appended catalogs uniquely retrieved and replayed;
* parent curriculum memory and manifest unchanged;
* zero false authorizations, false denials, or live mutations.

Utility ranks eligible proposals but cannot bypass authority, overlap, cost,
prerequisite, replay, or immutable-clone gates. The selected catalogs are
appended only to a clone; the parent memory remains untouched.
