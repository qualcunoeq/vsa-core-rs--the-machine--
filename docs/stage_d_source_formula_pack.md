# Stage D: source-derived declarative formula pack

This milestone separates domain education from execution code. Four sequence
and series identities are stored as source-cited `FormulaRecord` data and
executed by one generic rational expression interpreter. No formula-specific
evaluation branch or production registry mutation is used.

Theorem.” The frozen independent corpus is recorded in
`docs/stage_d_source_formula_pack.json` with SHA-256
`a700457863ab3ccf7d4e78ecfba4d8f988f77e7ffead7fad5d05a623df7176d6`.
