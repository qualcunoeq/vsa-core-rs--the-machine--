# Stage A: polynomial and number-theory composition

This campaign validates a narrow typed handoff: a finite-field polynomial
evaluation produces an explicit residue, which may feed modular inversion only
when both the prime field and number-theory modulus agree. Ambiguous field
interpretations and composite-modulus routes remain non-authorizable.

The independent corpus contains 240 cases: 120 supported, 40 ambiguous, and 80
refused, with both artifacts replayed and tamper-tested.
