# Stage H: source-derived science law pack

This milestone extends the source-derived curriculum beyond pure mathematics.
Four classical science laws are stored as cited declarative records and run by
one generic exact rational expression interpreter. The pack requires an
explicit SI-consistent unit scope and preserves source assumptions; it refuses
unknown laws, missing quantities, incompatible units, and singular inputs.

The independent campaign is recorded in `docs/stage_h_science_law_pack.json`.
